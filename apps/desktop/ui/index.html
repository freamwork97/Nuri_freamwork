        브라우저는 Chrome 창에서 열립니다

        AI 자동화는 PC에 설치된 진짜 Chrome을 전용 창으로 열어 사용합니다. Google 로그인도 그 창에서 그대로 됩니다. 한 번 로그인하면 계속 유지됩니다.

        위 주소창과 탭은 그 Chrome 창을 조작합니다. 평소 쓰는 Chrome과는 따로 분리된 프로필입니다.

        대기

        AI 계정 연결

        모든 모델은 공식 CLI의 구독 로그인으로만 실행됩니다. API 키(종량제)는 차단되어 사용량이 구독 플랜에서 차감됩니다.

        계정 상태 확인 중…

        브라우저 로그인 페이지에 코드가 표시되면 붙여넣으세요.

        스킬 · 플러그인 · MCP

        어시스턴트 모드와 브라우저 에이전트의 '위임' 단계에서 각 플랫폼에 설치된 기능을 그대로 사용합니다.

        무엇을 도와드릴까요?

        명령하면 AI가 왼쪽 브라우저를 직접 보고, 클릭하고, 입력하며 작업을 수행합니다.

        준비 중…
        Enter 실행 · Shift+Enter 줄바꿈
        작업 예약

        앱이 켜져 있을 때(트레이 포함) 정해진 시간에 실행됩니다. 앱이 꺼져 있던 동안 지난 예약은 건너뜁니다. 설정 > 일반에서 "Windows 시작 시 자동 실행"을 켜 두면 앱을 열지 않아도 됩니다.
        예약 실행 중 질문·승인에 5분 동안 답이 없으면 AI가 스스로 판단해 계속합니다(결제 승인은 거부). 반복 예약은 지난 실행 결과를 참고하므로 "새로 올라온 것만" 같은 작업도 할 수 있습니다.
