# Naver Search Skill

이 스킬은 네이버(Naver)의 실시간 검색어, 주요 뉴스 기사, 쇼핑 상품 최저가를 브라우징하여 요약 보고합니다.

## 사용법
- 사용자가 "네이버에서 [키워드] 검색해줘" 또는 "오늘 네이버 주요 뉴스 알려줘"라고 요청할 때 자동 발동합니다.
- 네이버 메인 또는 검색 결과 페이지의 ARIA 스냅샷을 분석하여 검색창(`searchbox`)과 헤드라인 링크(`link`)를 실시간 추적합니다.
- 검색 결과 상위 3~5개 항목을 추출하여 가격 또는 기사 요약 형태로 출력합니다.
